# Brand logo files (`public/brands/`)

**Rule:** a logo is shown only to identify the brand of a listed product.
- It does not imply affiliation. The footer says the site is independent and not affiliated with AliExpress or the brands shown.
- Logos are used **only** from sources whose copyright licence allows reuse.
- An official mark is never drawn or imitated. A brand without a free file keeps the typographic monogram (first letter + name).
