# Brand logos

Put each brand's **official** logo here, as SVG (preferred) or PNG with a
transparent background, named by the brand slug: `xiaomi.svg`, `anker.svg`,
`ugreen.svg`, `baseus.svg`, `lenovo.svg`, `dreame.svg`, `roborock.svg`,
`ecovacs.svg`, `amazfit.svg`, `insta360.svg`, `qcy.svg`, `tineco.svg`.

Then set `logo: "/brand-logos/<slug>.svg"` for that brand in
`lib/dealpilot/brands.ts`. Brands without a logo show their name instead.

Use only files you obtained from the brand (press/media kit or brand
guidelines page) or from an affiliate program's approved brand assets, and
follow that brand's logo usage rules. Do not redraw, recolour or trace logos.
The logos sit on white tiles, so use the version made for light backgrounds.
